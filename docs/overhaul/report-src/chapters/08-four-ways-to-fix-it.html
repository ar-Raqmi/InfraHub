Four ways to fix it

From seat belts to a full price catalogue

Four designs, from the smallest change to the biggest. Effort is a rough size, not a quote: S = days, M = one to two weeks, L = a month or more.

Option A · effort S

One library, with seat belts

Keep one library; snapshot it on every Simpan Pustaka (library_snapshots), stamp each project with the sebutharga it was priced under (rate_label), mark rows whose rate was typed by hand.

UI: a “Kadar: MPS/SH/302/25” chip, a picker warning “projek ini di bawah kontrak lama”, a Sejarah Pustaka list.

Risk: it warns but does not prevent. Two contracts at once is impossible.

Option B · effort M · recommended

A rate book per contract

Make the contract a record (contracts) and give each one its own copy of the library (rate_book_groups, with ids kept identical across copies). Add projects.contract_id. Both editors read only the project’s own book.

UI: a Kontrak list in Settings with the Pustaka inside each contract; the contract shown on the project header and in the picker title.

Risk: a wording fix must be made per book; the PT must remember to close old contracts; ids must stay stable.

Option C · effort L

Catalogue + price lists

Split “what the item is” (catalogue_items, never priced) from “what it costs” (price_lists + price_list_rates). Explode the 107 JSON groups into about 500 catalogue rows and 499 rate rows.

UI: the Pustaka rebuilt as a grid, one column per contract, with side-by-side comparison and percentage uplift.

Risk: the biggest rewrite: settings, API, both editors, templates. The 331 orphan rows need manual mapping.

Option D · effort M–L

Option B + immutable versions

As B, but a book is never edited in place: each publish creates a numbered version (rate_book_versions). A project is pinned to a version at lantikan; a correction becomes version 2 and old work orders stay on version 1.

UI: as B, plus Terbitkan versi and a version history with differences.

Risk: more concepts for staff. Only worth it if rates really change inside a contract period.

Pick this one if…

A · you need protection within days and accept that it only warns.

B · each sebutharga has its own schedule and you want the system to enforce it. Recommended.

C · you want year-on-year rate comparison built in and can afford a rebuild.

D · rates really change inside a contract period (question 5, chapter 90).
