Dollars are not what was spent

The $101.61 is a list price. The work was billed in plan quota, not dollars, so the quota readings are the real cost: 72 % of a session and 13 % of the week by the end.

  • Wave 1 (F and D): session 9 % to 28 %.
  • Wave 2 (K, P1, P2, O, then merge and the preview deploy): session 28 % to 72 %.
  • The week moved 8 points, 5 % to 13 %.

Inference The readings are three snapshots, not a per-agent bill. Which builder used how much quota is not known.

Three habits that paid off

  • Run every spec again after each merge. Builders’ specs go stale the moment another builder changes the UI they select on.
  • Read the deploy config before the deploy. The production-binding risk was visible in wrangler.toml and nowhere else.
  • Break it on purpose once. A negative control costs minutes and shows the check is alive.

Inference These are lessons drawn from the list above, not rules any builder was given.
