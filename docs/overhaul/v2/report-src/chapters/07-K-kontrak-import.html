What it built

Two screens and a wizard, all on one URL (/kontrak) that keeps its place in the address bar: back, forward and shared links work. Every status change, upload, match decision and publish lands in the change log with who, when and a diff.

Same two screens at 430 px: the register, and one contract with its rate book. Kontrak is on the phone tab bar, so an officer can import a sebutharga from the phone.

Register and detail

Filters by status, kind and text. A purple identity header for the contract, four tiles (projek, projek draf, panel, versi), and the actions Import BQ Excel, Aktifkan and Tutup.

Panel and book

Add, remove and reorder panel companies, with a per-company cap and a cap meter (amber when over; a warning only). A rate-book browser from category down to variant, searchable, for any version.

Version log

A commit list per contract (vN, message, TERBIT or DRAF, source LEGACY / IMPORT / CLONE / EDIT) with a diff viewer between any two versions.

The import wizard: five steps, one decision that matters

The parser (F’s domain code) reads each cell. Step 4 is the only place a person must decide: a line that was reworded cannot be matched by script with certainty, so it is shown old against new, with a similarity score. Publishing is blocked while any suggestion is still pending.

On a phone one suggestion fills a sheet, with big Terima and Tolak buttons, then jumps to the next pending one.

Where AI is, and is not

The AI-assisted match button renders nothing unless the server config says ai.matchSuggest: true. The deterministic parser reached 0 warnings on the real file, so the switch stays off and no AI route exists yet. The word-level highlighting in the side-by-side card is display only.
