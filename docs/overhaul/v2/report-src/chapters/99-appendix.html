Deploy the isolated preview

# docs/overhaul/v2/tools/deploy-v2-preview.sh: refuses any name without "v2-preview" and the production D1 id ./deploy-v2-preview.sh resources # create D1 + R2 (idempotent); prints the D1 id ./deploy-v2-preview.sh seed <d1-id> # anonymised seed + migrations, first time only ./deploy-v2-preview.sh deploy <d1-id> # build overhaul/v2 and deploy to Pages project infrahub-v2-preview

Glossary

Malay terms keep their spelling in the app. The English gloss is for you, as owner and engineer; the app itself stays Malay.

Sebuthargatender / quotation
The contract (code such as MPS/SH/302/25). In v2 it owns its rates.
Buku Kadarrate book
The priced list of work items of one sebutharga, kept as numbered versions.
Kontrakcontract
The screen and the record for a sebutharga.
DRAF / AKTIF / DITUTUPdraft / in force / closed
The three contract statuses. A new project defaults to the AKTIF one.
TERBITpublished
A rate-book version that is official. DRAF versions are still being reviewed.
Panelapproved companies
The companies allowed to work under a panel sebutharga.
BQbill of quantities
A project’s priced list of work, copied from the book of its sebutharga.
Pustakalibrary
The BQ library in Tetapan. Now the AKTIF contract’s rate book.
Perlu harga semulaneeds re-pricing
A draf project whose rates may no longer match its sebutharga.
No. Indenorder number
Once issued, it locks the project’s sebutharga.
Tetapan Organisasiorganisation settings
Profile, logo, document texts, lists and dated rules.
PJAproject officer
Prices and runs a project. Staff appear as “PJA 01…” in the seed.
LADliquidated damages
Denda kelewatan: a daily charge for late completion, from a dated rate.
LoClate-claim penalty
Denda lewat tuntutan: a daily charge after a grace period.
CPCcompletion certificate
Perakuan Siap Kerja. Starts the defects period.
DLPdefects liability period
Tempoh Tanggungan Kecacatan: 6 months by default.
BLRbase lending rate
An input of the LAD formula, valid from a date.
Peringatan 1–3reminders 1 to 3
The three notice letters sent to a company.
Padananmatch
A link from a new rate-book line to an old one.
Samasame
Same code, wording and rate as the old line.
Kadar berubahrate changed
Same line, new rate.
Perkataan berubahwording changed
A kept link with different wording. A suggestion for a person.
Baharu / Dibuangnew / removed
A line only in the new file / only in the old book.
Terima / Tolakaccept / reject
The two answers to a suggested match.
Aktifkan, Tutup, Padamactivate, close, delete
The contract actions.
Skop laporanreport scope
Which sebutharga, and which year or range, a report counts.
Julat tersuaicustom range
A date range on Tarikh Buka (opening date).
Pusat kawalan / Hari inicontrol centre / today
The dashboard on desktop / on the phone.
Perlu tindakanneeds action
The worklist card on the dashboard.
Menunggu kertas kerjawaiting for paperwork
Siap Sebenar is set but the claim or hand-over is missing.
Siap Sebenaractual completion
The date the site work really finished.
Teks dokumendocument texts
The printed wording, editable in Tetapan Organisasi.
Akses terhadrestricted access
What a non-admin sees on the organisation page.
Lantikan / Serah tapakappointment / site handover
Two dates in a project’s life, used as LAD date fallbacks.
