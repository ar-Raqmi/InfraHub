Projects list, and a report scope that labels its own totals

Totals come from one filter state

  • The summary, the PDF summary and the scope count use only the projects in scope. Search, status and PJA narrow the list, not the totals. This fixes the old flaw of balances computed from the filtered list.
  • Allocation and balance appear only when the scope sits inside one financial year; otherwise “—” with an amber note.
  • A negative balance is red. Manual deductions (Lain-lain, YDP) are editable only when the scope is the selected year.
