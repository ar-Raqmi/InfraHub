One admin page, five tabs

Only an administrator can open it; a PJA sees “Akses terhad”. Each tab saves through the API and shows its own history from the change log.

At 430 px: no horizontal overflow, no control under 44 px, no input under 16 px (probe on all five tabs).

Logo

Upload (downscaled to a PNG), use the original seal, or print none. A non-square logo is stretched into the existing fixed boxes.

Senarai

BP, Zon, Mukim and Unit: rename a label, reorder, deactivate. Codes cannot change, so old projects still match. Unit starts empty.

Login

The login page is re-skinned in the new design and shows “Digunakan oleh …” with the organisation’s name and logo from the settings.

How it was proved: the paper does not change unless a setting does

A harness runs the real PDF exporters in Chromium, once from a snapshot of the pre-change source and once from the new code, over 10 document types and 3 sample projects. Each PDF is read back with pdftotext -layout and the folders are compared with diff -r.

The acceptance spec (10 checks)

As admin it saves a short name, a Peringatan 1 paragraph and a new BLR dated in the future, and checks the change log holds all three. With BLR 6.65 moving to 7.65 on a future date, the LAD for a test project is RM 8.77 today and RM 10.14 on the effective day. The Notis preview shows the new paragraph; pja01 sees “Akses terhad”; the originals are restored. Local 10/10, preview 10/10.

Accountability

Every save writes a change-log entry. A policy added for a later date does not change the LAD rate for an earlier date (e2e and unit test). The access guard is client-side only; the config API is not role-checked, and authentication is out of scope for this overhaul.

Inference What O could not check

  • The CPC, Aku Janji, LAD, LoC and Prestasi previews were not opened in a browser after the change; they share the PDFs’ code path, which was compared.
  • The Senarai save and the logo upload were not run through the UI (the API routes are F’s tested routes).
  • Phone layout at 430 only, not 390 or 360.
  • The uploaded logo in the letterhead comparison was set through the API.
